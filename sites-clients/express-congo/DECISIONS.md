# Décisions — 8 octobre 2026

| Contexte                    | Décision                                                                 | Alternatives et justification                                                                                                                                        |
| --------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dépôt presque vide          | Application autonome dans sites-clients/express-congo                    | Pas de remplacement des fichiers racine ni mélange avec d’autres clients                                                                                             |
| Stack                       | Next.js 16.4.0, React 19.3.0, TypeScript strict                          | Versions vérifiées sur le registre et verrouillées ; TypeScript 7 incompatible avec typescript-eslint, retour à 6.0.3                                                |
| Reprise sans compte externe | SQLite Node natif comme adaptateur local                                 | PostgreSQL Docker seul rendrait le lancement impossible sur cet hôte sans Docker. Schéma PostgreSQL préparé pour la cible ; aucun raccordement de production annoncé |
| Calcul                      | Fractions d’entiers BigInt, décimales françaises jusqu’à 6 chiffres      | Évite l’accumulation d’erreurs binaires et les arrondis commerciaux prématurés                                                                                       |
| Prix                        | Règles pures, centimes entiers, aucune règle active                      | Ne pas interpréter le prix maritime ambigu ni inventer un diviseur volumétrique                                                                                      |
| Documents                   | Stockage transactionnel privé en BLOB, quarantaine intégrale             | Aucun téléchargement tant que l’analyse et l’autorisation documentaire ne sont pas vérifiées                                                                         |
| Design                      | Bleu #143F86, rouge boutons #C71922, logo original                       | Rouge assombri pour contraste du texte blanc. Palette proposée, jamais présentée comme charte officielle                                                             |
| Typographie                 | Inter auto-hébergée, licence OFL conservée                               | Aucun téléchargement de police au build, aucun appel Google Fonts à l’exécution                                                                                      |
| Visuels                     | Bannières source à dimensions modérées                                   | Aucune photo ni partenariat inventé, droits inscrits EC-006                                                                                                          |
| Environnements              | Démo par défaut, build production bloqué jusqu’à validation/raccordement | Préserve les données non validées et évite une fausse plateforme prête à publier                                                                                     |
| Édition                     | Propositions texte rendues comme texte React, session opaque locale      | Pas de HTML utilisateur, pas de mot de passe de démonstration utilisable en production                                                                               |
| Redirection PDF             | Anciennes URL vers /tarifs tant qu’aucune grille n’est validée           | Aucun téléchargement ne présente la source historique comme une offre applicable. Remplacer par un PDF versionné après EC-012                                        |
| Communication               | Aucun envoi réel ni déploiement                                          | Le cahier des charges exclut expressément ces actions                                                                                                                |

Le noyau opérationnel utilise des comptes fictifs préétablis, scrypt et des sessions hachées avec permissions par propriétaire/agence. Le second facteur administrateur est explicitement une simulation ; la cible exige encore Auth éprouvée/MFA. ESLint reste en 9.39.5 pour respecter les versions prises en charge par les plugins Next ; TypeScript est en 6.0.3. npm, utilisé pour préparer cette machine sans CLI standard, a été retiré des dépendances du projet.
